### 1.1 FlowerTune 20c fingerprint 与 split 断言（0 GPU）

```bash
exec bash
source /home/minghao/anaconda3/etc/profile.d/conda.sh
conda activate FedRepo2
cd /data2/minghao/code/FedPLoRA-main

export FLOWER_ROOT=$CODE_DIR/data/domain_benchmark_flowertune_mixed_20c_dir05
export FLOWER_AUDIT_ROOT=/data2/minghao/result/FedPLoRA/flowertune_20260717_strict_heldout_audit
mkdir -p "$FLOWER_AUDIT_ROOT/run_logs" "$FLOWER_AUDIT_ROOT/fingerprints"

nohup bash -lc '
set -eo pipefail
source /home/minghao/anaconda3/etc/profile.d/conda.sh
conda activate FedRepo2
cd /data2/minghao/code/FedPLoRA-main
python - "$FLOWER_ROOT" "$FLOWER_AUDIT_ROOT/fingerprints" <<'"'"'PY'"'"'
import collections
import json
import pathlib
import subprocess
import sys

root = pathlib.Path(sys.argv[1])
out = pathlib.Path(sys.argv[2])
out.mkdir(parents=True, exist_ok=True)
for seed in (42, 43, 44):
    split = root / f"seed_{seed}"
    clients_path = split / "clients.json"
    if not clients_path.is_file():
        raise SystemExit(f"[flower-strict][error] missing {clients_path}")
    clients = json.loads(clients_path.read_text(encoding="utf-8"))
    counts = collections.Counter(str(c["domain"]) for c in clients)
    if len(clients) != 20 or len(counts) != 4 or set(counts.values()) != {5}:
        raise SystemExit(f"[flower-strict][error] expected 4 domains x 5 clients, got {dict(counts)} in {split}")
    fp = out / f"seed_{seed}.json"
    subprocess.run(["python", "utilities/benchmark_fingerprint.py", str(split), "--output", str(fp)], check=True)
    print(f"[flower-strict][ok] seed={seed} clients=20 domains={dict(sorted(counts.items()))} fp={fp}")
PY
' > "$FLOWER_AUDIT_ROOT/run_logs/fingerprint_flowertune20c_3seeds.log" 2>&1 &
```

# 第三部分：运行顺序建议

1. 先跑 `1.1` fingerprint；通过后跑 `1.2` smoke；smoke 通过后跑 `1.3` FlowerTune strict held-out 三 seeds。  
2. 同事资源充足时并行启动第 2 节 1.7B，但 1.7B 单机上建议串行，避免显存争抢。  
3. G3 参照界优先跑 `3.2 centralized-per-domain`；local-only 如果采用 NX4 复用，可以跳过 `3.1`。  
4. G4/G5/G7 都是 135M 轻实验，可在 G1 完成后并行补。  
5. G10/G12 可与写作并行，但 `diag_subspace_AB` / `diag_b_swap` 仍会占用 GPU，建议放在空闲卡或夜间。

【注意事项】

1. 不再改算法，不再开大范围扫参；本文件只补证据链。
2. FlowerTune strict held-out 必须设置 `EXPECTED_NUM_CLIENTS=20`，否则 preflight 会按 35c 判错。
3. centralized-per-domain 必须使用真实 7c split，不能用 35c 代替。
4. 1.7B seeds43/44 是高成本实验；D-8 仍未跑完时，论文中按 seed42 单点 + caveat 呈现。
5. 本文件中的 loop 会启动多个独立 nohup；如果服务器 GPU 紧张，请逐条拆开粘贴。
