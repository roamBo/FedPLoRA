## 1. A 行空间几何（域内 / 域间 / 随机 null）

**脚本**：`scripts/Analysis/diag_subspace.py`

**在回答什么（D1–D3）**：


| 代号     | 含义                       | 怎么读                                          |
| ------ | ------------------------ | -------------------------------------------- |
| **D1** | 同域两客户端的 A：逐元素差 vs 子空间主夹角 | 元素差大但夹角小 → gauge 在搅局，需要 DCR/对齐；两者都小 → A 几乎一样 |
| **D2** | ‖A_i−A₀‖/‖A₀‖ 更新幅度       | 中位数 <3% → 1 epoch 更新太小，换聚合器可能没用              |
| **D3** | 域内 / 域间 / 随机 null 主夹角    | 域间 > 域内 且 域间 < 随机 → 有跨域结构，聚合 A 有意义           |


```bash
CUDA_VISIBLE_DEVICES=1 nohup python -u scripts/Analysis/diag_subspace.py \
  --model "$MODEL_PATH" \
  --benchmark_dir "$BENCHMARK_DIR" \
  --lora_r "$LORA_R" --lora_alpha "$LORA_ALPHA" --lora_dropout "$LORA_DROPOUT" \
  --batch_size "$BATCH_SIZE" --max_seq_length "$MAX_SEQ_LENGTH" \
  --torch_dtype "$TORCH_DTYPE" --target_modules "$TARGET_MODULES" \
  --gradient_checkpointing \
  --max_steps 0 --seed "$SEED" \
  --out artifacts_35c/diag/diag_subspace_A_seed${SEED}.json --save_figs \
  > log_diag/diag_subspace_A_seed${SEED}.log 2>&1 &
```

**产物**：`artifacts_35c/diag/diag_subspace_A_seed42.json` + 可选 fig；终端/`log_diag/*.log` 末尾有 `[判读]` 摘要。

## 2. A 行空间 vs B 列空间（域信号在 A 还是 B）

**脚本**：`scripts/Analysis/diag_subspace_AB.py`

每个客户端本地训完后，分别对 **A 的行空间**、**B 的列空间** 算域内/域间/随机 null 主夹角，得到 **ratio = (inter−intra)/(null−intra)**。

- **B 的 ratio ≫ A 的 ratio** → 域特异主要在 B → 「只共享 A」合理  
- **A、B 差不多** → 域信息也进了 A → 只聚合 A 可能丢域信息

```bash
CUDA_VISIBLE_DEVICES=1 nohup python -u scripts/Analysis/diag_subspace_AB.py \
  --model "$MODEL_PATH" \
  --benchmark_dir "$BENCHMARK_DIR" \
  --lora_r "$LORA_R" --lora_alpha "$LORA_ALPHA" --lora_dropout "$LORA_DROPOUT" \
  --batch_size "$BATCH_SIZE" --max_seq_length "$MAX_SEQ_LENGTH" \
  --torch_dtype "$TORCH_DTYPE" --target_modules "$TARGET_MODULES" \
  --gradient_checkpointing \
  --max_steps 0 --seed "$SEED" \
  --out artifacts_35c/diag/diag_AB_seed${SEED}.json --save_figs \
  > log_diag/diag_AB_seed${SEED}.log 2>&1 &
```

## 3. 同域 B 互换（B 可共享性）

**脚本**：`scripts/Analysis/diag_b_swap.py`

对每个客户端 i，在自己域的 held-out 上比较：


| 组合                | 含义        |
| ----------------- | --------- |
| `(A_i, B_i)`      | 本地基线      |
| `(A_i, B_j)`，j 同域 | 同域 B 能否替用 |
| `(A_i, B_k)`，k 跨域 | 跨域对照（应更差） |


**判读**：

- Δ_intra ≈ 0 且 Δ_intra ≪ Δ_inter → 同域 B 可互换 → FedPLoRA「B 私有但域内可去噪/共享」有依据  
- Δ_intra ≈ Δ_inter → B 高度客户端独有 → 更像 FedSA，B 必须严格私有

```bash
CUDA_VISIBLE_DEVICES=1 nohup python -u scripts/Analysis/diag_b_swap.py \
  --model "$MODEL_PATH" \
  --benchmark_dir "$BENCHMARK_DIR" \
  --lora_r "$LORA_R" --lora_alpha "$LORA_ALPHA" --lora_dropout "$LORA_DROPOUT" \
  --batch_size "$BATCH_SIZE" --max_seq_length "$MAX_SEQ_LENGTH" \
  --torch_dtype "$TORCH_DTYPE" --target_modules "$TARGET_MODULES" \
  --gradient_checkpointing \
  --max_steps 0 --seed "$SEED" \
  --eval_max_batches 20 --n_peers 4 --n_cross 2 \
  --out artifacts_35c/diag/diag_b_swap_seed${SEED}.json \
  > log_diag/diag_b_swap_seed${SEED}.log 2>&1 &
```

## 4. 推荐执行顺序

```bash
# 1) 环境 + 下载模型（若尚未下载）
export CODE_ROOT=/data/yaominghao/gb/FedPLoRA
export MODEL_ROOT=/data/yaominghao/gb/models
export DATA_ROOT="$CODE_ROOT/data"
cd "$CODE_ROOT" && mkdir -p log_diag artifacts_35c/diag
bash scripts/RunScripts/download_diag_models_modelscope.sh

# 2) source 配置 A，选一个 MODEL_PATH，先 --max_steps 60 冒烟，再 max_steps 0 全量

# 3) 三项诊断 1→2→3 可并行，改各命令里 CUDA_VISIBLE_DEVICES=1 为 2、3 等

# 4) （可选）换成配置 B（Llama-8B）再跑一遍，与主实验 scale 对齐

# 5) 看结果
tail -f log_diag/diag_AB_seed42.log
python -m json.tool artifacts_35c/diag/diag_AB_seed42.json | head -40
```

三项可**并行**占不同 GPU；每项都是：**各客户端顺序本地训 1 轮 → 抽 A/B → 算几何/互换 → 写 JSON**。
